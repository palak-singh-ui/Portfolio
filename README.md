# Palak Singh Portfolio

A responsive dark-theme React portfolio built with Vite.

## Run locally

1. Install Node.js.
2. Extract this ZIP and open the `palak-portfolio` folder in VS Code.
3. Open the terminal in that folder and run:

   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL printed by Vite (usually http://localhost:5173).

## Personalize before publishing

- Put your resume PDF in `public/resume.pdf` (create the `public` folder if needed).
- Replace the GitHub profile URL in `src/App.jsx` with your actual GitHub profile.
- Add actual project demo and repository URLs in the `projects` array (`live` and `github`). The buttons appear when those values are filled.
- Review the skills and project descriptions to ensure they reflect your current experience.
